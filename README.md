The notebook computes the dynamical diagnostics (magic, scrambling, anticoncentration, fermionic non-Gaussianity) and the quantities that set the cost of the leading classical simulation algorithms (inverse participation ratio, Pauli-path weights, Majorana degree distribution). 
Running it reproduces the calculations and the figures of the paper.
Use:
pip install -r requirements.txt
jupyter notebook Code_(Noisy_Quantum_Diagnostics_and_Simulability).ipynb

Circuit averages use seeded generators, so the numbers are reproduced exactly.
